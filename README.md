# Sculpt Art AR

Страницы скульптур с просмотром в дополненной реальности (model-viewer: Quick Look на iPhone, Scene Viewer на Android).

## Добавить работу
```sh
./sculpt add ~/Downloads/лошадь_03.stl horse --title "Лошадь" --meta "Бронза, 2025" \
  --desc "Короткий текст о работе" --height 0.4
```
- `horse` — адрес страницы (`.../sculpt-ar/horse/`), только латиница.
- `--height` — реальная высота в метрах: в AR скульптура встанет в натуральную величину. Без него телефон подберёт размер сам.
- `--faces 200000` — сколько треугольников оставить (по умолчанию 100 тыс., больше Android может не потянуть).
- `--color 0.55,0.38,0.22` — цвет материала (пример: бронза).
- `--usdz файл.usdz` — свой USDZ для iPhone (необязательно).

Повторный `add` с тем же адресом заменяет модель, а QR-код остаётся прежним.

## Другие команды
- `./sculpt preview` — посмотреть сайт локально (http://localhost:8765)
- `./sculpt list` — список работ
- `./sculpt remove horse` — удалить работу
- `./sculpt build` — пересобрать страницы и QR после правки `works.json` или `site.json`

## Настройки (`site.json`)
- `base_url` — адрес сайта, например `https://ваш-ник.github.io/sculpt-ar` (нужен для QR-кодов)
- `site_url`, `site_label` — ссылка на ваш основной сайт

QR-коды для печати лежат в `qr/` (SVG для типографии, PNG для всего остального).
